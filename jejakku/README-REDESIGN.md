# Jejakku UI Redesign — Starter

Redesign awal Jejakku dengan identitas visual Travel Journal + Explorer + personal diary.

## Yang diperbarui
- Home: sapaan personal, ringkasan perjalanan, peta mini ilustratif, daftar jejak terbaru, dan tombol tambah jejak.
- Palet warna: forest green, sage, cream, apricot, dan charcoal.
- Bottom navigation: Home, Jelajah, Jurnal, Statistik.

## Catatan penting
- Ini adalah tahap UI dengan data contoh dari `src/data/activities.ts`.
- Peta pada Home masih berupa ilustrasi UI, belum peta interaktif atau GPS sungguhan.
- Tombol Jelajah saat ini membuka halaman `/search` yang sudah ada.
- Supabase, autentikasi register/login, upload foto, dan database online belum diintegrasikan pada versi ini.
- Folder `node_modules` sengaja tidak disertakan agar file ZIP lebih kecil. Setelah mengekstrak, jalankan `npm install`.

## Menjalankan di Expo Go
1. Ekstrak ZIP.
2. Buka folder project di VS Code.
3. Jalankan `npm install`.
4. Jalankan `npx expo start`.
5. Scan QR code dengan Expo Go di HP. Pastikan laptop dan HP berada di jaringan yang sama.
